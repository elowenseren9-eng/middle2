# 研究二 正则清洗与日期校验

## 官方资料

[MDN JavaScript 正则表达式指南](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Regular_expressions)

## 商户名清洗

表达式 `/\s+/g` 用于把连续空白替换为一个普通空格：

- `\s`：匹配空格、制表符、换行等空白字符。
- `+`：前面的空白字符连续出现一次或多次。
- `g`：全局查找，替换字符串中的全部匹配项。

先调用 `trim()` 去掉首尾空白，再调用 `replace(/\s+/g, " ")` 合并中间空白。例如 `"  校园   打印店  "` 会得到 `"校园 打印店"`。

## 日期结构校验

表达式 `/^(\d{4})-(\d{2})-(\d{2})$/` 的含义：

- `^` 与 `$`：限制必须从字符串开头完整匹配到结尾。
- `\d{4}`：四位年份。
- `-`：日期分隔符。
- `\d{2}`：两位月份和两位日期。
- 三组圆括号：保存年、月、日，供后续转换。

正则只能确认格式，不能判断 2 月 30 日。因此代码还使用 `Date.UTC` 创建日期，再逐项比较年、月、日，避免仅凭格式误判。
