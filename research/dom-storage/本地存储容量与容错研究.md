# localStorage 容量与容错研究

## 资料结论

MDN 说明 Web Storage 通常按来源限制为 10 MiB，其中 `localStorage` 约 5 MiB、`sessionStorage` 约 5 MiB。超过配额时，浏览器会抛出 `QuotaExceededError`，因此写入操作应放在 `try...catch` 中。

## 实验方法与结果

“容量实验”按钮使用独立临时键，以 256 KiB 字符为步长逐次覆盖写入，最多尝试 12 MiB 字符。2026-09-18 在本机 Chrome 的本地 HTTP 环境中：

- 最后一次成功写入约 4.75 MiB 字符数据；
- 下一步写入捕获到 `QuotaExceededError`；
- `finally` 块清理了临时键；
- 清理后旅行收藏业务键仍然存在，页面功能正常。

这里的 4.75 MiB 是测试字符串长度的近似值；浏览器实际计量方式、已有数据、隐私模式和浏览器类型都会影响可用容量，代码不能依赖一个固定的数字。

## 容错策略

- 读取时捕获 JSON 解析错误，并恢复为空数组；
- 写入时捕获配额异常，页面显示“存储空间不足”的友好提示；
- 实验数据使用专门键，并确保无论成功或失败都清理；
- 不在容量实验中删除业务数据。
